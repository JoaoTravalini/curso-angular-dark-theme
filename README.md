# **📌 Descrição do Projeto - Dark Theme**  
Este projeto consiste em um Site para visualização do funcionamento do Dark Theme, utilizando **Angular** e **Tailwind**. O objetivo é praticar o uso do framework e as respectivas linguagens utilizadas.  

### 🎥 **Vídeo para visualização do projeto:**  
[Assista no Google Drive](https://drive.google.com/file/d/1hqbHXz0TgOSHM1lIsXnqZ5dFvisyguP8/view?usp=sharing)  

## 🛠 **Tecnologias Utilizadas**  
- Angular  
- HTML  
- CSS  
- Tailwind
- TypeScript  

## 🚀 **Como executar o projeto**  
1. Clone o repositório 
2. Execute npm install no terminal do projeto
3. Execute ng s no terminal
